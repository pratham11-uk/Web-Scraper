# Web-Scraper
THIS WEB SCRAPER IS BASED ON SIMPLE FRAMEWORK.
IT USES LIBRARIES SUCH AS REQUESTS , BEAUTIFULSOUP AND LXML
REQUESTS HELPS US TO APPROACH THE TARGET SITE AND FETCH RAW DATA IN FORM TEXT STRINGS .
BEAUTIFULSOUP WITH THE HELP OF LXML PARSER PARSEES THE RAW DATA AND COVERTS IT INTO STRUCTRED HEIRARCHICAL TREE
THEN BEAUTIFULSOUP CONVERTS THAT INTO PYTHON OBJECT KNOWN AS SOUP 
THEN USING SOUP OBJECT WE CAN ACCESS DATA USING FIND AND FIND_ALL METHOD OF SOUP OBJECTS
FINALLY WE STORE THAT DATA INTO A CSV FILE FOR LATER OPERATIONS
